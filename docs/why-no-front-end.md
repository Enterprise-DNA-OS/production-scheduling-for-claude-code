# Views without a front end

The useful record is the operation, its resource pair, its deadline and the reason it cannot run. Ask the coding agent to read it or change it through the CLI. HTML routing cards and the production-week snapshot can be opened and printed without a server.

A screen provides drag-and-drop planning, live shop-floor updates, a mobile timer and visual resource substitutions. This base provides none of those. Enterprise DNA can build the screens and connections the factory wants into its version. The current scheduler is a transparent weekday heuristic, not SkyPlanner's optimisation engine.

Generated views are snapshots. Replan and regenerate after input changes. Saved plans retain the input fingerprint for traceability but do not reserve actual equipment or release work.
